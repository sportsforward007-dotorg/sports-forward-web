# Website Development Rules

Before making changes:

1. Analyze affected files.
2. Explain planned changes.
3. Wait for approval.

Never:

* Delete pages without approval.
* Change DNS settings.
* Change GitHub Actions deployment workflows.
* Remove SEO metadata.

Always:

* Preserve existing URLs.
* Preserve responsive design.
* Test builds before committing.

After changes:

* Summarize files changed.
* Explain testing performed.
* Explain deployment impact.
